# Unslip のインストーラ

打ち間違いを直しながら変換する、macOS 用の日本語入力「Unslip」のインストーラを置いています。

- ダウンロードと説明：https://unslip.jp
- 最新版：[Releases](https://github.com/kbizikav/unslip-releases/releases/latest)（`Unslip.pkg`、Apple の公証済み）
- 動作環境：macOS 14 以上、Apple Silicon（M1 以降）

14 日間は無料ですべての機能を使えます。利用規約・ライセンスは https://unslip.jp/terms をご覧ください。言語モデルの重みは CC BY-SA 4.0 です。
